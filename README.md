# 필라테스 시퀀스 빌더

회원 프로필과 메인 기구·집중 부위를 고르면 수업 시퀀스를 만드는 정적 웹앱입니다.
서버 없이 `index.html`과 `data.js`만으로 작동합니다.

## 수업 구성

1. 서서 하는 스트레칭: 5분
2. 박스/보수 스텝업, 빠르게 걷기, 니킥, 런지 조합 유산소: 3~5분
3. 매트 복부: 최대 5분
4. 선택 기구 메인: 힙/하체/상체/코어/전신 중 한 부위를 중심으로 구성
5. 쿨다운: 5분

메인 파트는 비교적 쉬운 동작부터 강한 동작 순서로 정렬됩니다. 회원의 주의사항과 초급 레벨도 후보 필터에 반영하지만, 자동 생성 결과는 반드시 강사가 최종 확인해야 합니다.

## 새 동작 추가

`동작 데이터 편집` 탭에서 기구를 선택한 뒤 새 동작명, 카테고리, 집중 부위, 시간을 입력하고 `+ 동작 추가`를 누르세요.

- 추가한 동작은 즉시 시퀀스 생성 후보에 포함됩니다.
- 직접 추가한 동작만 완전히 삭제할 수 있습니다.
- 기본 동작과 직접 추가한 동작 모두 시간·스프링·제외 여부를 수정할 수 있습니다.
- 직접 추가한 데이터는 현재 브라우저의 `localStorage`에 저장됩니다.

## 가장 빠른 무료 배포: Cloudflare Pages 직접 업로드

1. 이 폴더를 ZIP으로 압축합니다.
2. Cloudflare에 무료 가입한 뒤 `Workers & Pages`로 이동합니다.
3. `Create application` → `Get started` → `Drag and drop your files`를 선택합니다.
4. ZIP 파일을 올리고 `Deploy site`를 누릅니다.
5. 발급된 `https://프로젝트명.pages.dev` 주소를 동생분에게 보내면 됩니다.

업데이트할 때는 같은 프로젝트에서 `Create a new deployment`를 누르고 새 ZIP을 다시 올리면 됩니다. 별도 빌드, 서버, 명령어가 필요 없습니다.

## 아이패드와 컴퓨터에서 사용할 때

배포 주소는 두 기기의 Chrome/Safari에서 똑같이 열립니다. 다만 회원, 저장 시퀀스, 직접 추가한 동작은 브라우저별로 따로 저장됩니다.

한 기기에서 입력한 내용을 다른 기기로 옮기려면 `회원 관리`의 `내보내기`로 백업 JSON을 만든 뒤 다른 기기에서 `불러오기`를 사용하세요. 실시간 자동 동기화는 서버가 필요하므로 이 무료 최소 버전에는 포함하지 않았습니다.

## 파일 구성

- `index.html`: 화면, 시퀀스 생성 규칙, 브라우저 저장 기능
- `data.js`: Barrel, Cadillac, Chair, Mat, Reformer 교재 기반 동작 목록

교재의 손글씨 표시는 오인식 가능성이 있으므로, 제외 동작과 세팅은 강사가 최종 검수해야 합니다.
